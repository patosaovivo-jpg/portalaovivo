Como publicar:
  1. Preencha os dados e clique "Gerar e copiar"
  2. Clique "Criar no GitHub" (abre com o nome do arquivo pronto)
  3. Cole o conteúdo no campo de edição
  4. Se tiver imagem: salve o arquivo na pasta assets/images/ antes
  5. Clique "Commit changes"
